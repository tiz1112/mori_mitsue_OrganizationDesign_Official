# もり みつえ 事業サイト(仮公開版)

福祉事業所(放課後等デイサービス・児童発達支援)の経営者に向けた、組織づくり伴走サービスの1ページサイトです。

- 状態: **確認用の仮公開版**(2026年11月20日 時点)
- 作りの形: HTML 1枚と写真2枚。ビルドや設定は不要です。

---

## 1. 中身

```
morimitsue-site/
├── index.html          ページ本体(文字・デザインはすべてこの1ファイル)
├── README.md           このファイル
└── photos/
    ├── mori-studio-mono.jpg       プロフィールに使用
    ├── mori-avatar-mono.jpg       相談窓口の丸写真に使用(上の写真から顔を中心に正方形に切り出したもの)
    └── mori-seated-wide-mono.jpg  「信条」の帯に使用
```

## 2. 見かた

- **パソコンで確認する**: `index.html` をブラウザにドラッグすれば表示されます。
- **書体はネット接続が前提**: Google Fonts から読み込んでいます(Shippori Mincho / Zen Kaku Gothic New / Cormorant Garamond)。オフラインでは代わりの書体で表示されます。
- **写真の場所**: `photos` フォルダは `index.html` と同じ階層に置いたままにしてください。動かすと写真が出なくなります。

## 3. 公開のしかた

フォルダの中身をそのままアップロードするだけで動きます。

- **レンタルサーバー**(エックスサーバー、さくら など): FTP で公開フォルダに `index.html` と `photos` を置く。
- **無料の静的ホスティング**: Netlify(フォルダをドラッグ&ドロップ)、Cloudflare Pages、GitHub Pages など。

`README.md` は公開しなくても問題ありません。

## 4. 本番公開の前にやること

この版は確認用です。下の項目が残っています。
行番号は編集すると変わるので、**「探す文字」で検索**して該当箇所を見つけてください。

### 4-1. 確認用の表示を外す

| 何を | 探す文字 | どうする |
|---|---|---|
| ページ上部の赤い帯 | `確認用の仮ページです。【 】の箇所は準備中` | その `<div …>…</div>` の1行を丸ごと削除 |
| 検索除け | `<meta name="robots" content="noindex, nofollow">` | 行ごと削除 |
| タブの題名 | `(仮公開)` | 削除 |

### 4-2. 空欄を埋める(【 】の箇所)

| 何を | 探す文字 | 入れるもの |
|---|---|---|
| 考え方の型の例の結果 | `【実例の数字】` | 本人の実例での変化 |
| メールアドレス(フッター) | `【メールアドレス】` | 公開用のアドレス |

**実績の数字**は2026年11月に入力済みです(2023年と2026年の比較)。数字が更新されたら「06 実績」の表を書き換えてください。

### 4-3. LINE・電話のボタンをつなぐ

今は2つとも、押すとページ内の相談欄に戻るだけです。

| ボタン | 探す文字 | 書き換え |
|---|---|---|
| LINEで相談する | `LINEで相談する` の直前にある `href="#contact"` | `href="https://lin.ee/xxxxxxx"`(LINE公式アカウントの友だち追加URL) |
| 電話で相談する | `電話で相談する` の直前にある `href="#contact"` | `href="tel:0000000000"`(ハイフンなし) |

- **電話番号は画面に出ません。** `tel:` の中に書くだけなので、画面上に番号は表示されません。ただし、ページのソースを見れば番号は分かります。
- **パソコンでは電話がかかりません。** 電話ボタンはスマホでのみ発信できます。

### 4-4. 申し込みフォームを動かす

今のフォームは見た目だけで、送信できません(「審査に申し込む」を押すと「まだ送信はできません」と出ます)。
どれか1つを選んでつなぎます。

| 方法 | 手間 | 向いている場合 |
|---|---|---|
| **A. 外部フォームに飛ばす**(Googleフォーム / formrun など) | 小 | まず早く公開したい |
| **B. フォーム送信サービスにつなぐ**(Formspree / Netlify Forms など) | 中 | 今のデザインのまま受け付けたい |
| **C. 自前のサーバーで受ける**(PHP など) | 大 | すでにサーバーがある |

B を選んだ場合の作業:

1. `<form` の行に、送り先(`action="…"`)と `method="POST"` を足す。
2. 入力欄4つ(`id="f-name"` `f-org` `f-mail` `f-msg`)に、それぞれ `name="…"` を足す。
3. ボタン `id="apply-button"` の `type="button"` を `type="submit"` に変える。
4. ファイル末尾の `<script>…</script>`(送信を止めている部分)を削除する。

### 4-5. 本人に確認してほしい文章

制作側で書いた文章です。本人の言葉に置き換えるか、内容が正しいかを確認してください。

- **「02 考え方の型」の三つの問い**: 「変えられる課題か」「誰の何につながっているか」「続けるために、何が足りないか」。本人の考え方として違和感がないか。
- **「02 考え方の型」の場面の例**: 支援記録の例は制作側が作った説明用の例です。本人の実例に差し替え、「結果」の【実例の数字】を埋めてください。
- **「03 方法」の一段落**: 在り方→理念→方針→しくみ の説明。
- **「信条」の一文**: 「言葉は、現場で使われて／はじめて理念になる。」
- **「05 事業所に残るもの」の4項目**: 理念と行動の言葉/役割と判断基準の設計図/面談と育成の型/次の管理者。
- **サービスの中身**: チームビルディングとチームマネジメントの進め方(各3〜6項目)、理念と行動の言葉づくりの進め方。
- **プロフィール**: 経歴の順番、「職員約50名」「在籍児童約150名」の数字。
- **受け入れの条件**: 「同時にお引き受けする事業所は5社まで」。
- **料金**: 08章の表。サイト内で料金が載っているのはここ1か所だけです。

## 5. 写真について

- **出せる写真**: 本人の写真のみです。子ども・職員の写真は使いません。
- **差し替えるとき**: 同じファイル名で上書きすれば、HTMLを触らずに差し替えられます。
- **写真の使用許可**: 撮影したカメラマンに、Webサイトでの使用許可を取ってあるか確認してください。

## 6. 公開してよい情報の範囲

- **屋号**: 「もり みつえ」を看板にしています。本名は載せていません。
- **会社名**: 載せていません。
